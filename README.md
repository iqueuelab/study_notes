# Study Notes

Open [index.html](index.html) to browse subject chapters, common summaries and current-affairs topics. Search titles, subjects or dates, or filter by collection and subject. The pages work offline.

Rebuild the home page after adding subject notes:

```sh
python3 tools/build_notes_home.py
```

Publishing current-affairs notes refreshes it automatically. Downloaded source PDFs are excluded from the current-affairs Git snapshot.
