# Alaknanda and Panch Prayag

## River route
- Garhwal Himalayas, **Uttarakhand**; meltwaters of **Satopanth and Bhagirath Kharak glaciers**; approximately **190 km** to Devprayag.
- Main Ganga headstreams: **Alaknanda and Bhagirathi**; join at **Devprayag → Ganga**. Alaknanda contributes the larger flow, while Bhagirathi is traditionally treated as the source stream.
| Confluence, upstream → downstream | Alaknanda joins |
| --- | --- |
| Vishnuprayag | Dhauliganga |
| Nandprayag | Nandakini |
| Karnaprayag | Pindar |
| Rudraprayag | Mandakini |
| Devprayag | Bhagirathi |
- Valley links **Badrinath, Joshimath** and routes towards **Hemkund Sahib**; Hemkund is reached via a tributary-valley route, not situated on the main Alaknanda channel.
- Uttarakhand Char Dham: **Badrinath, Kedarnath, Gangotri, Yamunotri**; not all four lie along the Alaknanda itself.
## Landslide-dam risk
- January 2025 source cites **IIT Roorkee** study: landslides can block the river, create temporary reservoirs, then breach and release flood pulses.
- Combine slope monitoring, drainage/land-use safeguards, upstream blockage detection and downstream warning/evacuation. See [landslides](landslides.html) through the main topic index if browsing across subjects.
