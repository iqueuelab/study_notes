# SAKSHAM: integrated counter-drone command grid

## October 2025: procurement initiated
- Indian Army initiated procurement of indigenous SAKSHAM, developed with Bharat Electronics Ltd, Ghaziabad: **Situational Awareness for Kinetic Soft and Hard Kill Assets Management**. The embedded clipping says procurement initiated; the “Army inducts” headline does not prove every unit is already deployed.
- Modular command-and-control grid on the secure Army Data Network integrates sensors, radar tracks and counter-UAS assets into a Recognised UAS Picture (RUASP). GIS/3D displays and AI-assisted threat assessment support commanders; reported features are capabilities sought/described, not proof of perfect autonomous detection or engagement.
- **Detect → identify/track → assess → select soft/hard response → coordinate engagement.** Soft kill disrupts navigation/communications through jamming/spoofing; hard kill physically defeats drones using appropriate kinetic/directed-energy assets. The command grid integrates assets rather than itself being every gun, missile or laser.
- Described tactical air-littoral coverage extends to about 3,000 m/10,000 ft. Links with Akashteer improve friendly/neutral/hostile-airspace coordination; they reduce fratricide risk without guaranteeing zero friendly-fire incidents. Layered defence needs reliable communications, discrimination, countermeasure choice and trained human oversight.
