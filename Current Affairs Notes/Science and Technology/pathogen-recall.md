# Pathogen and vaccine recall

## Facts from the embedded PYQ-recall graphic
| Disease / organism | Recall |
| --- | --- |
| Viruses | Require living host cells for replication; cannot multiply in a cell-free artificial culture medium like suitable bacteria/fungi |
| Common cold | Multiple viruses; adenoviruses can cause some cases |
| HIV/AIDS | HIV is a **retrovirus** |
| Hepatitis B / C | **B has a vaccine; C has no licensed vaccine**—graphic reverses this distinction |
| Zika / dengue | **Aedes** vectors; Zika sexual transmission also possible |
| Viral hosts | Viruses infect animals, plants, bacteria and fungi; bacteriophages infect bacteria |
| Foot-and-mouth disease / cowpox | Infectious conditions relevant to animal-health recall; pathogens differ |
| Athlete's foot | **Fungal** infection |
